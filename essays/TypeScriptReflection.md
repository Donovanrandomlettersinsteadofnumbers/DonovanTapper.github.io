I am completely new to using TypeScript and still getting used to software engineering. So far, TypeScript feels similar to Java, but it has been a while since I have used java, and there still differences between the two that have been hard to get used to. I am still having trouble remembering all the things required to make code that actually work. However, TypeScript feels fairly intuitive with how things need to be written despite the fact that I can not remember any of it.

To learn TypeScript the class I am taking is using athletic software engineering. I find doing practice WODs to be helpful, but I have to make sure I don't wait till the last second to do the WOD before it is due. The WODs being timed can be pretty stressful, but if I fully understand what I am supposed to be doing the time becomes much less of an issue. I just need more practice using TypeScript to get comfortable using it.
