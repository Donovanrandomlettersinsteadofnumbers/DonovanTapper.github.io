<h3>Learning Coding Standards</h3>
Throughout learning how to using coding standards, it has been helpful as well as annoying at times. Using ESLint is very helpful when it comes to making code more readable and helping condense code to take up less space sometimes. However, the extra errors that ESLint creates can be annoying when I have some other issue with the code that I am trying to fix. It makes it more difficult to actually find the issue. It is also annoying when doing WODs, as they take up extra time and focus away from completing the main code. It makes it just a bit harder to finish the WOD in time. Although, if I was just better at coding this wouldn't be an issue at all.
